개인정보처리방침

ShareFiles는 파일 공유에 필요한 정보를 다음과 같이 처리합니다.

접근하는 정보와 목적

파일 내용과 파일명·크기·수정 시각 등의 정보를 목록 표시, 업로드·다운로드 및 전송 확인에 사용합니다. 연결 인증 정보와 폴더 식별자는 Google Drive 인증과 공유 폴더 접근에 사용합니다.

앱이 생성하거나 사용자가 접근을 허용한 파일에 대한 권한을 요청합니다. Google 비밀번호를 입력받거나 보관하지 않습니다.

보관과 공유

파일은 Google Drive와 사용자가 저장한 기기에 보관됩니다. 같은 연결 설정을 사용하는 사람은 공유 파일에 접근할 수 있습니다. 연결 인증 정보는 기기의 보안 저장소에 보관하며, 전송 과정에서 기기에 임시 파일을 만들 수 있습니다.

앱은 HTTPS로 Google에 직접 연결하며 별도의 파일 중계 서버를 사용하지 않습니다. Google의 데이터 처리에는 Google 개인정보처리방침이 적용됩니다.

삭제와 권한 철회

앱의 연결 해제로 해당 기기의 저장된 인증 정보를 지울 수 있습니다. Google 접근 권한은 소유자가 Google 계정 설정에서 철회할 수 있습니다.

Drive 파일은 소유자가 Google Drive에서 삭제합니다. 다운로드한 파일과 전달받은 설정 파일은 사용자가 직접 삭제해야 합니다. 연결 해제나 권한 철회로 이미 공유된 파일 사본이 삭제되지는 않습니다. 공유 데이터에 관한 요청은 폴더 소유자에게 전달해 주세요.

이용 범위

Google 사용자 데이터를 판매하거나 광고·범용 AI 모델 학습에 사용하지 않습니다. Google API에서 받은 정보의 사용과 다른 앱으로의 전송은 제한적 사용 요건을 포함한 Google API 서비스 사용자 데이터 정책을 따릅니다.

안내 홈페이지

이 홈페이지는 자체 쿠키나 분석·광고 스크립트를 사용하지 않습니다. GitHub Pages에 게시되면 호스팅 제공자가 보안 목적으로 IP 주소 등 접속 정보를 처리할 수 있습니다. 자세한 내용은 GitHub 개인정보처리방침을 참고해 주세요. 데이터 처리 방식이 바뀌면 이 페이지에 반영합니다.
